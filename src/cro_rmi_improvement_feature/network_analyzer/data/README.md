# Data Directory

This directory contains all data files for the Risk Network Visualization System.

## Structure

- **`raw/`** - Raw input data files (Excel files, CSV files, etc.)
  - Place your original risk data Excel files here
  - These files should not be modified by the application
  
- **`processed/`** - Processed data files generated by the application
  - Pickle files with processed risk data
  - Network data structures
  - Embeddings and relationship classifications
  - These files are generated by the data processing pipeline

## Usage

1. Place your raw risk data Excel files in the `raw/` directory
2. The data processing pipeline will read from `raw/` and output to `processed/`
3. The visualization system will read from `processed/` for display

## File Naming Convention

- Raw files: `company_name_risk_data.xlsx`
- Processed files: `company_name_processed.pkl`, `company_name_embeddings.pkl`, etc.

## Data Privacy

- Raw data files may contain sensitive information
- Processed files should be anonymized where possible
- Consider adding this directory to `.gitignore` if working with sensitive data
